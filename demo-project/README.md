# Rain Code Studio Demo Project

A sample repository for testing Rain Code Studio desktop capabilities.

## Structure
- `src/index.ts`: Application entry point.
- `src/calculator.ts`: Sample math operations.
- `src/parser.ts`: Sample string parsing utility.
- `package.json`: Project manifest.

This demo project can be loaded into Rain Code Studio in Phase 1 to verify project selection, file tree navigation, and desktop-to-backend communication.
