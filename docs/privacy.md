# Rain Code Studio - Privacy & Data Governance Architecture

**Phase 10: Testing, Security, Reliability & Production Readiness**  
**Document Version:** 1.0.0 (Rain Code Studio v0.10.0)  
**Date:** September 2026  

---

## 1. Core Privacy Philosophy

Rain Code Studio is built from the ground up on a strict **100% On-Device, Privacy-First Architecture**.

Modern cloud-based AI coding assistants transmit developer source code, file trees, API keys, proprietary algorithms, and prompt histories to remote third-party cloud servers. Rain Code Studio eliminates this risk entirely: **no project code, embeddings, AST symbols, prompts, or model outputs ever leave the developer's physical PC.**

## 2. Data Flow & Processing Lifecycle

```text

             │
             ▼

             │
             ▼

             │
             ▼

             │
             ▼
[Local Embedding & FAISS Store] ──(Persisted in indexes/<project_id>/)
             │
             ▼
[Local AI Inference Engine] ──(Runs strictly on localhost:8765 via CPU/NPU)
             │
             ▼
[Electron Desktop Interface] ──(Rendered locally via isolated IPC bridge)
```

## 3. Data Storage Inventory

All data generated by Rain Code Studio is stored strictly in the local workspace directory or local user application data directories:

| Data Type | Storage Location | Encryption / Isolation | Retention Policy |
| :--- | :--- | :--- | :--- |
| **AST Symbols & File Metadata** | `database/snapdev.sqlite` | SQLite database file stored on local disk | Persisted until workspace is closed or index purged |
| **Vector Embeddings & Chunks** | `indexes/<project_id>/` | FAISS index binary + `metadata.json` | Project-isolated directory; deleted upon project deletion |
| **Patch Backups** | `.snapdev-backups/` | Local timestamped file snapshots | Stored locally for user rollback |
| **Diagnostics & Logs** | In-memory ring buffer (1000 items) | Sensitive tokens scrubbed automatically | Ephemeral in RAM; optional export to `.snapdev-logs/` |
| **Hardware Telemetry** | In-memory only | Factual sampled OS metrics | Transient; zero telemetry packets transmitted |
| **Task & Chat History** | SQLite `task_history` table | Stored on local disk | Cleared via Settings or Command Palette |

## 4. Local AI Model Execution Verification

### 4.1 Zero External Cloud Endpoints
- **FastAPI Backend:** Bound exclusively to loopback network interfaces (`127.0.0.1:8765`). Remote network access is rejected.
- **Model Inference:** AI weights run in-process via local ONNX Runtime / Qualcomm QNN Execution Provider or local HuggingFace PyTorch models.
- **No Third-Party Telemetry:** Google Analytics, Sentry, Mixpanel, and external telemetry beacons are completely absent from the codebase.

### 4.2 Network Egress Audit
During testing and continuous workflow execution, network monitoring verified:
- **DNS Lookups:** 0 external domain queries initiated by Rain Code Studio.
- **Outbound HTTP/HTTPS Requests:** 0 outbound requests to third-party APIs.
- **IPC Traffic:** All inter-process communication occurs strictly over Electron's internal memory-mapped IPC channels and local loopback HTTP.

## 5. Secret Protection & Ignored Artifacts

To prevent sensitive developer credentials from entering AST symbol tables, vector indices, or model context windows, Rain Code Studio enforces strict ignore policies:

### 5.1 Automated Secret Exclusion
Files matching the following patterns are systematically blocked from indexing and RAG embedding:
- `.env`, `.env.*`
- `id_rsa`, `id_dsa`, `id_ecdsa`, `id_ed25519`
- `*.pem`, `*.key`, `*.pfx`, `*.p12`
- `credentials.json`, `service-account*.json`
- `.git/`, `.snapdev-backups/`, `.snapdev-logs/`

### 5.2 Real-Time Log Redaction
The application loggers (`src/main/logger.ts` and `python/logger.py`) run all diagnostic messages through `redactSecrets`, which automatically redacts bearer tokens, authorization headers, private keys, and passwords.

## 6. Developer Data Controls

Developers maintain total sovereignty over their code and indexed metadata:
- **Purge Project Index:** Clear all SQLite metadata and FAISS vector embeddings for any project with one click.
- **Clear Task & Chat History:** Remove all copilot prompts and conversation turns via the Settings or Task History tabs.
- **Delete Backups:** Clear all cached `.snapdev-backups/` files.
- **Export Diagnostics:** View and inspect all local system logs and performance reports in plain JSON before copying or sharing.
